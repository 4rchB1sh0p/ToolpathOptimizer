# Documentation Instructions

## Scope
Apply to all Markdown files in `docs/`.

## Rules
- Keep content short and clear.
- Prefer bullet lists over long paragraphs.
- Explain what changed and why in a few lines.
- Include only essential examples.
- Avoid repeating details already documented elsewhere.
- Prefer updating existing docs instead of creating duplicates.

## Format Template
Use this compact structure when adding/updating docs:
1. Purpose
2. Key Points
3. Usage or Example (optional)
4. Validation or Notes (optional)

## Length Guideline
- Default to brief documentation.
- Keep entries as concise as possible while still useful.
