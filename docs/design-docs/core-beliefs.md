# Core beliefs

Status: Accepted | Last reviewed: 2026-11-19

## Purpose and scope
- Principles used to resolve design trade-offs across all layers.

## Key points
- Correctness before cleverness; evidence before AI narrative.
- Constrained feasible routes before shorter routes.
- Units are types, not labels.
- Offline-first industrial workflows; no machine execution.
- Deterministic and inspectable results; reversible user decisions.
- Smallest useful scope; clear failure semantics (fail closed).
- Industrial customers own their engineering decisions.

## Acceptance criteria
- ADRs that trade off a belief state it in their Consequences section.

## Risks
- Beliefs treated as slogans → reviewers cite them in decisions.
